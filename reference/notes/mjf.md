I have not run MJF, so this is an outside view. It shares the polymer physics of SLS but delivers energy differently: an inkjet prints a fusing agent where the part should be, and a lamp heats the whole layer [1]. The carbon-based fusing agent is why parts come out grey.

For me, that matters only in production, where color, consistency, and cost per part drive the decision. When prototyping, I care much less which powder process made the part.
